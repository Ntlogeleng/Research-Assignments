Foundational Analytics, KPIs and Marketing Analytics

Project Overview

This project provides an introduction to key concepts used in data analytics, business intelligence, performance measurement and marketing analytics. It focuses on understanding how organisations collect, measure, analyse and communicate data to support data-driven decision-making.
The project is divided into four main areas:

Foundational Concepts of Analytics

Data Measurement and Reporting

Customer and Sales KPIs

Marketing and Campaign Analytics

The objective is to develop a practical understanding of how data can be transformed into meaningful information that helps businesses monitor performance, understand customers and evaluate marketing activities.
